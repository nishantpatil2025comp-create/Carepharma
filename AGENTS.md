\# Project Rules


- This is a Flutter/Dart application.

- Use null-safe Dart.

- Follow Flutter best practices.

- Keep widgets small and reusable.

- Do not put business logic directly inside UI widgets.

- Keep API/database logic inside services.

- Do not create unnecessary dependencies.

- Do not modify unrelated files.

- Before making architectural changes, explain the change.

- Do not rewrite working code unless necessary.

- Run dart analyze after significant changes.

- Run flutter test after significant changes.

- Keep the project compatible with Android.
